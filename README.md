# Verilog codes


## Requirements

Ensure the following tools are installed on your system:

| Tool | Purpose | Installation |
|------|----------|--------------|
| **Icarus Verilog (iverilog)** | Compiles and runs Verilog simulations | [Download here](https://bleyer.org/icarus/) or install via `sudo apt install iverilog` |
| **GTKWave** *(optional)* | View signal waveforms | `sudo apt install gtkwave` or download from [gtkwave.sourceforge.net](http://gtkwave.sourceforge.net/) |
| **VS Code** *(optional)* | Convenient for editing and running code | [Download VS Code](https://code.visualstudio.com/) |

## 📂 Typical Project Structure

```
├── design.v        # Your Verilog design module
├── testbench.v     # Testbench to verify the design
├── waveform.vcd    # (optional) Waveform output generated by simulation
└── README.md       # Documentation file
```

---

## 🚀 How to Compile and Run

### Step 1 — Compile

Run this command in your project directory:

```bash
iverilog -o <output_file> <design_file.v> <testbench_file.v>
```

**Example:**
```bash
iverilog -o testbench_out design.v testbench.v
```

This compiles both your **design** and **testbench** into an executable file named `testbench_out`.

---

### Step 2 — Simulate

Run the compiled simulation:

```bash
vvp <output_file>
```

**Example:**
```bash
vvp testbench_out
```

This will print simulation results to the terminal — for example, signal values or timing outputs depending on what your testbench displays.

---

### Step 3 — (Optional) View Waveform

If your testbench includes:
```verilog
$dumpfile("waveform.vcd");
$dumpvars(0, <testbench_module_name>);
```

You can visualize the simulation in **GTKWave**:

```bash
gtkwave waveform.vcd
```

This lets you see all signals (inputs, outputs, and internal wires) changing over time.

## 🧩 Testbench Guidelines

A typical testbench includes:
- **Instantiation** of the design module under test (DUT)
- **Stimulus generation** (input patterns)
- **Display statements** or **monitor blocks**
- (Optional) **Dumpfile setup** for waveform viewing

Example snippet:
```verilog
initial begin
  $dumpfile("waveform.vcd");
  $dumpvars(0, testbench);
  // Apply inputs and observe outputs
end
```

## 🧾 Example Workflow Summary

```bash
# 1. Compile
iverilog -o my_design_tb my_design.v my_design_tb.v

# 2. Run simulation
vvp my_design_tb

# 3. (Optional) View waveform
gtkwave waveform.vcd
```

---

## 💡 Notes

- Always name your design and testbench modules differently.
- Use `$display` or `$monitor` for output logs during simulation.
- For multi-file projects, include all `.v` files in the compile command.
- Use `-Wall` with `iverilog` to enable warnings:
  ```bash
  iverilog -Wall -o output.vvp *.v
  ```
